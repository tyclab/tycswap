      What happens
      
        
      Claude Code is signed in to one account at a time: its live login. {{.Name}} keeps a saved login for each of your accounts and copies one into the live login when you click Switch, or by itself with Auto-switch on.
      
        
      
      

      
      
        
      Getting started
      
        
        
          
      1. Add account… opens guided setup in a terminal: choose Sign in with Claude and sign in in the browser. The account is saved; the live login stays as it is.
        2. 
          
      2. Repeat for each account. Save current login saves the account Claude Code is signed in with now.
        3. 
          
      3. Turn on Auto-switch above the accounts, or click Switch on the one you want.
        4. 
        
      
        
      A setup token or an API key goes in with Add token…. Auto-switch never picks an API-key account; a switch to one asks first, since it is billed per token.
      
      
      

      
      
        
      Switching by hand
      
        
        
      
          
      Switch now
      Best takes the account Account order ranks first and stays if that is the live one; Next available takes the next account in slot order that is not at a limit. Neither picks a disabled or an API-key account.
      
          
      Use saved login…
      Writes that account's saved login over the live login without saving the outgoing one: for a live login that stopped working.
      
          
      Allow for start
      Lets {{.Name}} start switch to this account when it launches Claude Code with Auto-switch on.
      
          
      Remove…
      Deletes the saved login and the account's Fable login; the live login stays.
      
        
      
      
      

      
      
        
      Auto-switch
      
        
      One setting, shown above the accounts, on the Auto tab, in the tray and as {{.Name}} auto on / off. The line under the Auto tab's heading says who checks: a scheduler running {{.Name}} auto --once, or this dashboard at its Poll interval.

      Reading the meters
      
        
      Each account has a 5-hour and a weekly window; some plans add a weekly limit per model. A meter shows the share used and, underneath, when it resets: green below 70 %, amber from 70 %, orange from 90 %, red at 100 % (at limit). A dash means Anthropic reports no such window for that account (an Ultra login has no 5-hour limit); an empty meter means there is no recent reading.
      
        
      Best candidate is the account Auto-switch would take next. Sorting the table changes only the view.
      
      
      

      
      
        
      Fable logins
      
        
      An account can be signed in twice. The second sign-in, its Fable login, can go into the Fable store, which Fable sessions use, so they and your other sessions run on different accounts at once.
      
        
        
          
      • Add one: {{.Name}} add --login --lineage fable --slot N in a terminal. The first one turns the Fable store on. Not on macOS.
        • 
          
      • Which sessions: those started through {{.Name}} start whose model is Fable. All others use the live login.
        • 
          
      • On the page: Fable marks the Fable store's account, Fable login one it can use. Use for Fable moves the Fable store there and, like any switch by hand, holds its automatic moves for the Switch cooldown.
        • 
          
      • Automatic moves: only a scheduler's checks move the Fable store, never this dashboard's. They also keep the live login off the accounts the Fable store needs while another account is below every threshold.
        • 
          
      • Off: {{.Name}} switch --store fable --empty. Fable sessions then use the live login.
        • 
        
      
      
      

      
      
        
      Sessions
      
        
      The Sessions tab lists the running Claude Code sessions and the IDEs with the Claude Code extension. Stop ends a session; claude --continue in its folder resumes it. While an account has a Fable login, a session shows Fable store or default login once its status line has reported it, and nothing before.
      
      
      

      
      
        
      Updates
      
        
      The dashboard looks for a newer {{.Name}} and Claude Code every six hours (Check now asks at once) and installs one after you confirm; {{.Name}} upgrade updates {{.Name}} from a terminal. What is running keeps its old version until it is started again.
      
      
      

      
      
        
      Codex accounts
      
        
      Codex (ChatGPT) accounts have their own heading with Switch, Disable or Enable and Remove; + Add current Codex login saves the codex CLI's account. With Codex auto-switch on, a scheduler's checks rotate them, and this dashboard's do too when it started with Codex accounts. A running codex keeps its account until restarted; {{.Name}} codex alias names one.
